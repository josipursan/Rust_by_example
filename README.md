# Rust exercises
My personal favorite : https://github.com/mainmatter/100-exercises-to-learn-rust  
Has a book in PDF format and in Gtihub book format, as well as a lot of examples and snippets.  
A self-paced course with 100 progressively harder problems. Each exercise is a failing unit test you fix. The repo includes solutions and explanations, so you can learn idiomatic Rust step by step  
  
============================  
Another great resource, dealing with more complex techniques such as multi-threaded mailboxes, linked lists in Rust, etc:  
https://github.com/ferrous-systems/rust-exercises  
  
===========================  
  
A large collection of beginner-to-intermediate Rust problems. Each exercise comes with a solution and an explanation, so you can compare your approach and understand the reasoning :  
https://www.w3resource.com/rust/index.php  
  
============================  
  
The Rust By Practice site is a curated set of exercises across ownership, lifetimes, traits, concurrency, etc. This GitHub repo provides clear, documented solutions to all of them  
https://github.com/Lukman-01/rust-learn-by-practice/tree/master
